00 / Overview

google-stitch design system

Terminal console identity for www.jackzhaojin.com. JetBrains Mono headings with negative tracking, Inter body, sharp corners, 1px borders, bracketed counts and numbered // section labels. Light is the default; dark is the round's native palette.

System facts
OriginThe Google Stitch round of 2026-09-13. It produced the home page only, in dark, plus a light variant.
Origin folderlocal-only/stitch-2026-09-13/stitch-v1.html (dark document from line 682, light from line 1141); split copies in .playwright-cli/stitch/
Version0.1.0
Statusbeta round candidate, not deployed
ContractSPEC.md, round 2026-09-13

Identity

The round read like a console: a $ prompt before the breadcrumb, counts in square brackets, section labels written as // 01 / NAME, a lavender primary on a near-black ground, emerald and cyan as sparing accents. This system keeps those marks and drops what broke the rules: the fake telemetry bar, the invented facts, Tailwind, Material Symbols and the em dashes. The light theme is built from the round's light config as a first-class set, not a fallback.

Principles

  1. Facts over adjectives. Every number on a page comes from data or stays in brackets.
  2. Content is in the HTML. JavaScript switches theme, opens the nav, filters and sorts. It never supplies content.
  3. One system, two palettes. Every component renders in light and dark from the same markup.
  4. Clean over clever. 2px radii, 1px lines, no shadows except under the sticky header, no decoration that implies status.
  5. Readable by machines. Tables for facts, ordered lists for steps, one H1, headings in order, breadcrumb above the H1.

Quick start

Copy the head from SPEC section 3. The three stylesheets load in this order, and data-theme-default on html is light for every page in this round.

06 / Motion

Motion

Two durations and one easing. Color, background and border changes use --duration-fast (120ms). The nav panel uses --duration-base (200ms). Easing is cubic-bezier(0.2, 0, 0, 1). No entrance animations, no reveal on scroll, no pulsing dots.

hover me: 200ms standard

Reduced motion

Under prefers-reduced-motion: reduce every transition and animation is cut to 0.01ms and smooth scrolling is turned off. The status dot does not animate in either mode.

08 / Theming

Theming

Three choices: Light, Dark, System. The choice is stored in localStorage under jj-theme. Light and Dark set data-theme on html; System removes it, and a media query then follows the OS. The pre-paint snippet in head applies the stored choice before any stylesheet loads, so there is no flash. shared/theme.js wires every control on the page, keeps aria-pressed in sync, sets data-theme-effective and listens for OS changes while in System.

Live control

This is a second instance of the header control; both stay in sync.

Pre-paint snippet

<script>
(function(){var d=document.documentElement;d.classList.add('js');try{var s=localStorage.getItem('jj-theme');var def=d.getAttribute('data-theme-default')||'light';var c=(s==='light'||s==='dark'||s==='system')?s:def;if(c==='system'){d.removeAttribute('data-theme');}else{d.setAttribute('data-theme',c);}d.setAttribute('data-theme-choice',c);}catch(e){}})();
</script>

Selector structure

Because the dark set also applies to any element with data-theme="dark", a story frame on this page can be forced dark inside a light page.

:root, [data-theme="light"] { color-scheme: light; /* light semantic tokens */ }
[data-theme="dark"] { color-scheme: dark; /* dark semantic tokens */ }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]):not([data-theme="dark"]) { color-scheme: dark; /* dark tokens again */ }
}
  • Storage key jj-theme, values light, dark, system.
  • data-theme-default="light" on every page in this round.
  • color-scheme is set with each token set so form controls and scrollbars follow.

10 / Patterns

Patterns

Page anatomy

  1. Breadcrumb, directly above the H1, on every page except home.
  2. One H1. On home it is the name, with the positioning line under it.
  3. Byline with author link, published and updated dates in time, read or watch time, media type.
  4. Summary of 40 to 60 words as the first paragraph. No hero image between the H1 and it.
  5. Facts table.
  6. Body: H2s phrased as questions, ol for steps, table for comparisons.
  7. FAQ, related, author box.

Heading rules

H1, then H2, then H3, never skipping. Section labels are kickers, not headings. Card titles are H3 under a section H2. Footer column titles are H2.

Content in HTML

Every list, table and transcript is in the initial HTML. Filters hide with the hidden attribute and never remove. Nothing uses an opacity zero reveal.

Images and alt

Alt text is one sentence naming what a diagram shows and the entities in it. Decorative images get alt="". No fact lives only inside an image. Decorative SVG carries aria-hidden="true".

Theme default

data-theme-default="light" on every page in this round. system is reserved for the portfolio page later.

Why each slot exists, for humans, search and answer engines: seo-page-blueprint.md.
